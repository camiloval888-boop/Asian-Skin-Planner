# Asian Skin Planner

Agenda personal para organizar rutinas de skincare asiático (K-Beauty).

## Publicar en GitHub Pages
1. Descomprimí `asian-skin-planner-github.zip`.
2. Creá un repositorio en GitHub y subí el contenido de la carpeta `asian-skin-planner`.
3. Verificá que `index.html` quede en la raíz del repositorio.
4. Entrá a **Settings → Pages → Deploy from a branch → main → /(root)** y guardá.
5. Esperá a que GitHub Pages publique el sitio y abrí el enlace.

## Agregar al celular
- iPhone: abrí el enlace en Safari, tocá Compartir y elegí “Agregar a pantalla de inicio”.
- Android: abrí el enlace en Chrome y elegí “Instalar aplicación” o “Agregar a pantalla de inicio” si aparece.

## Datos y privacidad
Los datos se guardan en el almacenamiento local del navegador de este dispositivo. No se envían a servidores. Si borrás los datos del navegador, podés perder la información; usá la opción de exportación para guardar una copia.

La aplicación es una herramienta de organización y educación general. No brinda diagnósticos ni reemplaza la consulta con profesionales de la salud.
